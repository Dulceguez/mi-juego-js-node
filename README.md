# 🎮 Real-time Multiplayer Game (Node.js + Socket.IO)

Juego de preguntas y respuestas tipo tablero con soporte multijugador en tiempo real. 
Desarrollado con Node.js, JavaScript y WebSockets, permite la sincronización de jugadores, turnos y eventos del juego entre clientes conectados.

---

## Características

- Juego de tablero por turnos
- Sistema de dado para movimiento de jugadores
- Preguntas dinámicas cargadas desde JSON
- Soporte para múltiples jugadores en el mismo dispositivo
- Lógica backend con Node.js (versión servidor)
- Interfaz web desarrollada con HTML, CSS y JavaScript

---

## Tecnologías utilizadas

- Node.js
- JavaScript
- HTML5
- CSS
- JSON
